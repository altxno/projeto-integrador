# Semestre II — Projeto Integrador

## Briefing

Sistema WEB de gerenciamento de comissões para artistas independentes. 
O sistema desenvolvido é um **CRUD em Angular**, contemplando as operações de cadastrar (CREATE), visualizar (READ), editar (UPDATE) e excluir (DELETE) registros.

## Integrantes

- Altino Ávila
- Guilherme Diniz
- Pedro Augusto

## Stacks Utilizadas

- **Angular v22** — principal framework web
- **Angular Material** - biblioteca visual
- **Node.js 24 + npm** — gerenciamento de pacotes & ambiente de execução
- **JSON Server** — API Rest simulada para dados
- **Webstorm & VS Code** — IDEs utilizadas
